# Выгодно и с умом

Первый MVP финансовой платформы: визуальный каркас без реальных торговых операций, платежей, авторизации и внешних API.

## Установка и запуск
```bash
npm install
npm run dev
```
Откройте `http://localhost:3000`.

Для просмотра с телефона запустите `npm run dev -- --hostname 0.0.0.0`, узнайте локальный IP компьютера и откройте на телефоне `http://IP:3000` в той же Wi-Fi сети.

## Production build
```bash
npm run build
npm start
```

## Deployment на Vercel
Загрузите проект в GitHub, импортируйте репозиторий на Vercel и оставьте стандартные настройки Next.js. Альтернатива: `npx vercel` из папки проекта.

## GitHub Pages

Публикация запускается автоматически при каждом push в ветку `main`. Статическая версия доступна по адресу `https://app-easy-trade.github.io/vygodno-i-s-umom/`.

## Структура
- `src/app` — страницы и маршруты App Router
- `src/components` — переиспользуемые компоненты
- `src/data` — конфигурации навигации и торговых категорий
- `public` — статические ресурсы

Финансовые данные и функциональные блоки сейчас демонстрационные placeholders.
